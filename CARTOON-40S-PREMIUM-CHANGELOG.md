# Roof Roof — Cartoon 40s Premium

## Objetivo
Llevar la interfaz a una estética más cercana a la caricatura clásica de los años 40,
sin perder claridad de retail ni profesionalismo comercial.

## Cambios realizados

- Se refinó la capa visual **Cartoon Premium** con una influencia más clara de caricatura vintage / rubber-hose.
- Se cambió la tipografía de display a un tono más clásico y retro (`Concert One`) para headings y títulos de marca.
- Se reforzaron contornos, stickers, botones y navegación con detalles tipo ilustración vintage.
- Se añadieron detalles de línea punteada y subrayados tipo marcador para acercar la dirección visual a un look de póster clásico.
- Se pulieron títulos y tarjetas de **Compra por necesidad** con colores más expresivos y mayor jerarquía visual.
- Se mantuvo la estructura profesional del e-commerce: navegación, producto, filtros, carrito y CTAs siguen limpios y legibles.
- Se cuidó el responsive para que en móvil el estilo siga presente sin exceso visual.

## Archivos clave tocados

- `app/root.jsx`
- `app/styles/cartoon-premium.css`
- `app/components/AboutSection.jsx`

## Nota
No se cambió la lógica de Shopify, carrito, GraphQL ni rutas.

## Corrección posterior

- Se eliminó del proyecto la imagen proporcionada por el usuario, ya que fue compartida únicamente como referencia visual y no como recurso para integrarse en la interfaz.
- La dirección visual Cartoon 40s Premium se conserva mediante tipografía, color, contornos, stickers y microdetalles propios del sistema de diseño.
