# Retiro de imagen de referencia

- Se eliminó la imagen compartida por el usuario del código y de los assets del proyecto.
- Se retiraron su importación, markup y estilos asociados en la sección “Nuestra filosofía”.
- La imagen se utilizó únicamente como contexto visual para orientar el lenguaje Cartoon 40s Premium.
- Se conserva la dirección visual mediante tipografía, color, contornos, stickers y microdetalles propios del sistema de diseño.
- No se modificó la lógica de Shopify, las rutas, GraphQL, carrito ni funcionalidades comerciales.
